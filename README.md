# NutriLabel — Interactive Nutrition Intelligence Platform

Landing page + 13-screen interactive Android prototype (HTML, CSS, JavaScript; Tailwind compiled to a static CSS file).

## Run it
- **Quick:** double-click `index.html` (needs internet for fonts and icons).
- **While editing screens (recommended):** serve the folder, e.g. VS Code *Live Server* or
  `python -m http.server`, then open `http://localhost:8000`.
  Screens are fetched live from `screens/`, so edits show on refresh.

## Structure
```
index.html                     Landing page (header, 9 sections, phone frame, footer)
assets/
  css/
    tailwind.css               BUILT file — generated by `npm run build:css` (don't edit)
    base.css                   Reset + hidden scrollbars
    navigation.css             Smooth scrolling + header offset for anchor jumps
  js/
    site/navigation.js         Nav scroll-spy (active tab) + compact mobile menu
    landing/marketing-demo.js  "Problem" card toggle
    simulator/
      state.js                 Shared prototype state
      screen-navigation.js     jumpToSimulatorScreen(), bottom-nav highlight
      preferences.js           Chips + goal selection
      scanner.js               Torch + 4-step scan sequence
      scenarios.js             Standard / missing-fields / unknown scenarios, reset
      ingredients.js           Ingredient search + filters
      contribution.js          OCR submit + verification actions
      screen-loader.js         Loads screens/*.html into the phone
    generated/screens-bundle.js  AUTO-GENERATED fallback for file:// (don't edit)
screens/                       One file per phone screen (01 welcome … 13 education)
tools/bundle-screens.js        Regenerates the fallback bundle
tailwind.config.js             Theme tokens from DESIGN.md + files Tailwind scans
src/input.css                  Tailwind entry file
package.json                   Build scripts
```

## After editing a file in `screens/`
Edits appear automatically when served over http. If you open the page by double-clicking,
run `node tools/bundle-screens.js` once to refresh the fallback bundle.

## Tailwind build (only when you change classes or the theme)
```
npm install
npm run build:css      # or: npm run watch:css while editing
```
The built `assets/css/tailwind.css` is committed, so no build step is required to deploy.
